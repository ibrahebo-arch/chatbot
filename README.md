# VI Iraq 🇮🇶 — منصة طلب فيديوهات بالذكاء الاصطناعي

واجهة "مركز تحكم" داكنة بعرض الشاشة وباللغة العربية: صندوق دردشة في الأعلى (ChatGPT API) يحدّد منه الزبون الدقة (البكسل) والمدة واللغة وعدد الشخصيات بالكتابة أو بالأزرار مع السعر الفوري، وتحته شبكة بطاقات خضراء، بطاقة لكل فيديو باسم الملف يُشغَّل داخلها.

## التشغيل

```bash
npm install
cp .env.example .env     # ثم عدّل القيم
npm start                # http://localhost:3000
```

## ملف الأسرار `.env` (مخفي)

| المتغير | الوصف |
|---|---|
| `OPENAI_API_KEY` | مفتاح ChatGPT (adaptive_AI). لا يُرفع أبداً إلى GitHub |
| `OPENAI_MODEL` | الموديل، الافتراضي `gpt-4o-mini` |
| `BREVO_API_KEY` أو `RESEND_API_KEY` | مفتاح مزوّد البريد (واحد فقط يكفي) |
| `MAIL_FROM` | عنوان المرسل (Brevo: مرسل مُفعّل في حسابك – Resend: `onboarding@resend.dev` أو دومينك) |
| `MAIL_ATTACH_MB` | أقصى حجم مرفقات داخل البريد، الأكبر تُرسل كروابط (الافتراضي 10) |
| `MAIL_TO` | بريد الاستلام: `ibrahim2dms@gmail.com` |
| `ADMIN_TOKEN` | كلمة سر لإرسال بريد تجريبي عبر `POST /api/mail/test` (اختياري) |
| `PUBLIC_URL` | رابط الموقع العام، يُستخدم لروابط المرفقات الكبيرة داخل البريد |
| `ATTACH_LIMIT` | أقصى حجم لمرفق الدردشة (الافتراضي `200mb`) |

### ⚠️ المساعد لا يرد؟ (OpenAI)

1. يجب أن يوجد ملف `.env` فعلي (ليس `.env.example` فقط) وفيه `OPENAI_API_KEY`.
2. أعد تشغيل الخادم بعد أي تعديل على `.env` (`npm start`).
3. إذا كان هناك متغير `OPENAI_API_KEY` قديم في إعدادات Windows (متغيرات البيئة) فالخادم يتجاهله الآن ويأخذ القيمة من `.env`. يُفضّل حذفه من: Settings → System → About → Advanced system settings → Environment Variables.
4. عند التشغيل يطبع الخادم `AI: on` أو سبب التعطيل، وأي خطأ من OpenAI يظهر في الطرفية كـ `chat error:`.

### 📧 تفعيل البريد (Brevo أو Resend)

**Brevo (مستحسن – 300 رسالة يومياً مجاناً، ويرسل لأي بريد):**
1. أنشئ حساباً في brevo.com.
2. Senders, Domains & Dedicated IPs → Senders → Add a sender: أضف `ibrahebo@gmail.com` واضغط رابط التأكيد الذي يصلك.
3. SMTP & API → API keys → Generate: انسخ المفتاح إلى `BREVO_API_KEY` في `.env`.

**Resend (3000 رسالة شهرياً مجاناً):**
1. أنشئ حساباً في resend.com **بنفس البريد** الذي تستلم عليه الطلبات (`MAIL_TO`)، لأن Resend بدون دومين لا يرسل إلا إلى بريد صاحب الحساب.
2. API Keys → Create: انسخ المفتاح إلى `RESEND_API_KEY`، وضع `MAIL_FROM=onboarding@resend.dev`.

بعدها أعد تشغيل الخادم؛ يطبع `Mail: on` أو سبب المشكلة. للفحص: `GET /api/mail/test`. لإرسال بريد تجريبي:

```bash
curl -X POST http://localhost:3000/api/mail/test -H "x-admin-token: ADMIN_TOKEN"
```

## فيديوهات المعرض (للقراءة فقط)

لا يستطيع زوار الموقع رفع أو حذف فيديوهات المعرض؛ يمكنهم فقط إرفاق فيديو داخل الدردشة مع الطلب.

**من المجلد:** انسخ ملفاتك `.mp4` / `.webm` إلى `public/videos/` وأعد تحميل الصفحة.

اسم البطاقة = اسم الملف.

## ماذا يحدث عند "إرسال الطلب"؟

- يُحفظ الطلب محلياً في `orders/` (مخفي)، ومرفقات الزبون (صور/فيديو/ملفات من الدردشة) في `uploads/`.
- الزبون يستطيع إرفاق **فيديو** من زر 📎 ويظهر مشغَّلاً داخل الدردشة. الملفات التي تتجاوز معاً `MAIL_ATTACH_MB` لا تُرفق بالبريد بل تُرسل كروابط `PUBLIC_URL/uploads/...`.
- يُرسل بريد عبر Brevo/Resend إلى `MAIL_TO` يحتوي: الجودة، المدة، اللغة، عدد الشخصيات، السعر، التواصل، المحادثة كاملة، والمرفقات كملفات مرفقة بالبريد.

> المنصة حالياً لإستقبال الطلبات فقط ولا تُنتج فيديوهات تلقائياً.
