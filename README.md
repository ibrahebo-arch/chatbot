# VI Iraq 🇮🇶 — منصة طلب فيديوهات بالذكاء الاصطناعي

واجهة بتصميم iPhone وباللغة العربية: دردشة ذكية في الأعلى (ChatGPT API)، اختيار اللغة وعدد الشخصيات والجودة، شريط المدة مع السعر الفوري، وزر إرسال الطلب الذي يرسل كل شيء بالبريد.

## التشغيل

```bash
npm install
cp .env.example .env     # ثم عدّل القيم
npm start                # http://localhost:3000
```

## ملف الأسرار `.env` (مخفي)

| المتغير | الوصف |
|---|---|
| `OPENAI_API_KEY` | مفتاح ChatGPT (adaptive_AI). لا يُرفع أبداً إلى GitHub |
| `OPENAI_MODEL` | الموديل، الافتراضي `gpt-4o-mini` |
| `GMAIL_USER` | بريد المرسل: `ibrahebo@gmail.com` |
| `GMAIL_APP_PASSWORD` | كلمة مرور التطبيقات من Google (ليست كلمة مرور الحساب) |
| `MAIL_TO` | بريد الاستلام: `ibrahim2dms@gmail.com` |

كيف تحصل على App Password: حساب Google → الأمان → التحقق بخطوتين → App passwords → أنشئ واحدة باسم "VI Iraq" وانسخها إلى `.env`.

## رفع فيديوهات الخلفية

1. انسخ ملفاتك `.mp4` / `.webm` إلى `public/videos/`.
2. أعد تحميل الصفحة. تُشغَّل بدون صوت وتتبدّل تلقائياً بالترتيب الأبجدي.
3. يوجد زر `؟` داخل الموقع يشرح الخطوات للزبون/المدير.

## ماذا يحدث عند "إرسال الطلب"؟

- يُحفظ الطلب محلياً في `orders/` (مخفي).
- يُرسل بريد من `GMAIL_USER` إلى `MAIL_TO` يحتوي: الجودة، المدة، اللغة، عدد الشخصيات، السعر، التواصل، والمحادثة كاملة.

> المنصة حالياً لإستقبال الطلبات فقط ولا تُنتج فيديوهات تلقائياً.
