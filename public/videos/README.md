# 🎥 فيديوهات الخلفية

ضع هنا ملفات الفيديو (`.mp4` / `.webm` / `.mov`) وستُشغَّل تلقائياً في خلفية الموقع بالتناوب حسب الترتيب الأبجدي.

- يُفضَّل: بدون صوت، أقل من 20MB، دقة 1080p.
- مثال: `01-intro.mp4`, `02-baghdad.mp4`
- الفيديوهات لا تُرفع إلى GitHub (مستثناة في .gitignore) – ارفعها مباشرة إلى السيرفر.
